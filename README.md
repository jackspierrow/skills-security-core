# Security Core Curriculum (01–22)

The core 22-skill security curriculum: recon, vuln scanning, exploit dev, reverse engineering, malware, threat hunting, incident response, network, web, cloud, SOC, crypto, red/blue/purple team, mobile, OT/ICS, GRC, supply chain and threat intel.

Koleksi **22 skill** — bagian dari [skill-dari-hextor](https://github.com/jackspierrow/skill-dari-hextor). Tiap skill ada di foldernya sendiri, berisi `SKILL.md` (+ file pendukung).

## Cara pakai

Baca `SKILL.md` di folder skill yang kamu butuhkan, lalu ikuti instruksinya di agen AI kamu.
Tiap skill tetap memakai lisensinya masing-masing bila ada (lihat file `LICENSE` di folder skill).
